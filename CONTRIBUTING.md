# Contributing to qCoder (public repository)

This repository is published from **clean public export** commits. The internal development repository retains private history and must not push here directly.

## Maintainer workflow

1. Prepare a public-safe tree through the internal export process.
2. Push from a dedicated export clone (not the internal repo).
3. Run `scripts/qcoder-v0-release-check` before tagging releases.

## Community contributions

Issues and pull requests are welcome for the public Free line and Pro Preview shell.

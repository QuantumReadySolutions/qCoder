# qCoder 0.6.0a10

qCoder 0.6.0a10 is an unpublished successor candidate to the public qCoder 0.6.0a9
pre-release. It is not stable or generally available. Package-index availability and public
claims require separate lifecycle and Roadmap decisions.

## Contained reliability correction

- Exact Python, OpenQASM 2, and supplied-result files selected outside the active workspace retain
  their already-validated explicit-selection authority through canonical registration and local
  derivation.
- The visible artifact set remains exact. qCoder does not discover a directory, expand a glob,
  scan a repository, follow hidden alternatives, or infer another artifact.
- Local derivation remains local-only and passes no raw source, QASM, result, customer path, or
  customer filename to the protected service.
- The already-derived share-safe Run Summary may traverse the existing Current Build Context
  operation without exposing raw result data.
- Governed-change proposals stay within the published Context Bridge input contract and bind to
  the exact confirmed Intent Card already retained for the active loop.
- Governed-change parent transport uses only canonical current-session reference descriptors;
  parent artifact bodies remain local and immutable.
- Hosted comparison remains a separate binding-v18 operation. The service-side reliability
  correction is backward compatible with public 0.6.0a9 and does not add a tool, mode, profile,
  action, entitlement, token scope, persistence model, or history lookup.

## Preserved boundaries

- Exactly twelve Context Bridge tools, five Prompt Context modes, three Algorithm Blueprint
  profiles, and seven Decision Resolution actions remain.
- IDE write and execution authority remains separate from selected-artifact review.
- Governing change remains unconfirmed until separate explicit customer confirmation.
- Current-loop lineage stays immutable and stale state fails closed.
- No repository scan, autonomous edit or execution, project history, cross-session memory, or Pro
  behavior is added.

# qCoder 0.6.0a13

qCoder 0.6.0a13 is a public pre-release. It is not a stable or generally available release,
and package publication does not activate a named-client support claim.

This release preserves the exact qCoder 0.6.0a12 runtime behavior, connected-assistant binding
v19, schemas, twelve Context Bridge tools, five Prompt Context modes, workflow and retention
contracts, authority boundaries, artifact-access scope, dependencies, and entry points.

The release replaces transient candidate/publication wording in immutable package metadata with
durable publication-truthful pre-release wording. Release-control and qualification state remain
separate from package metadata.

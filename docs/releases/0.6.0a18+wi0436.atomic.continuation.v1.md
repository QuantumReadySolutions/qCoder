# qCoder 0.6.0a18+wi0436.atomic.continuation.v1

This is an unfrozen, unpublished WI-0436 development rehearsal identity. It is not a release
candidate and does not activate Tested, First-class, Client Compatibility, or public support.

The existing `create_algorithm_intent_card` operation now returns one qCoder-supplied atomic
continuation capsule whenever its exact card revision needs clarification. A client copies that
capsule unchanged and supplies only the customer-reviewed unresolved-field values plus the explicit
review assertion. It does not reconstruct or reconcile the card, internal contract, contract
digest, revision, or duplicate binding fields.

The capsule is self-verifying within qCoder's existing stateless local trust model: canonical
payload integrity, the card artifact digest, and the regenerated internal contract must all match.
No persistent signing secret, hidden lookup, or project history is introduced. Malformed, tampered,
stale, cross-card, cross-revision, forbidden, and unauthorized corrections fail closed with bounded
diagnostics and no raw-value echo or retention.

The change adds no public tool or authority category. It does not confirm intent automatically,
retain project state, execute code, alter WI-0435 causal evidence semantics, or change protected
production behavior. The twelve public Context Bridge tools and two private Current Loop
operations remain unchanged.

The preceding v43 development artifacts and plain a17 rejected candidate remain immutable evidence.

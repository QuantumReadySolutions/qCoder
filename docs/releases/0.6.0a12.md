# qCoder 0.6.0a12

qCoder 0.6.0a12 is an unpublished successor candidate to the public qCoder 0.6.0a11
pre-release at source freeze. Package-index publication remains a separate immutable lifecycle
fact.

This release advances the shared connected-assistant binding from v18 to v19. Its generic named-
workflow completion contract classifies existing canonical structured tool-result states as
non-terminal preparatory, customer-terminal outcome, genuine blocker, or customer authority / real
decision boundary. Routine continuation is allowed only inside the already-selected named qCoder
workflow and never broadens artifact access or customer authority.

For Evidence Review, existing `assistant_context_ready` is explicitly non-terminal and continues
quietly to the existing Result Review operation. Existing `result_review_context_card_ready` is
the customer-terminal outcome. The exact twelve Context Bridge tools and protected operations are
unchanged.

The same binding defines canonical structured `process_and_discard` as unambiguous evidence that
no customer artifact is retained for that exact operation. A literal empty retained-artifact list
remains sufficient when emitted but is not mandatory. Absent, ambiguous, contradictory,
free-form-only, or wrong-operation retention evidence fails closed.

This release adds no tool, Prompt Context mode, client profile, SDK, user ceremony, repository
discovery, file access, write/run authority, public client qualification claim, protected-service
revision, Account change, entitlement change, token change, consent change, billing change, or
website change.

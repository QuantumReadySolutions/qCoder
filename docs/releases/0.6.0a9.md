# qCoder 0.6.0a9

qCoder 0.6.0a9 contains the coherent OSS Local Evidence Experience for explicitly selected files.
At source freeze, the exact artifact pair is an unpublished candidate pending exact-artifact
qualification and a separate publication decision. This note describes version contents;
package-index availability remains a separate lifecycle fact.

## Included behavior

- `qcoder review local-evidence` for explicitly selected Python/Qiskit source, OpenQASM 2,
  supplied counts or supported result JSON, supported canonical evidence JSON, and bounded
  collections of individually listed files.
- Canonical Development Evidence, CircuitIR, result manifestation, Run Summary v2, Help v2,
  completion and operation receipts, and share-safe JSON and Markdown identities are reused.
- Default share-safe exports remove customer filenames, paths, and raw/private categories;
  separate flags opt in to each applicable category.
- Dot-prefixed files and resolved POSIX-style path segments are rejected, including hidden
  symlink targets. Windows hidden attributes and alternate data streams remain unqualified.
- Accepted adaptive-intent, recovery-policy, installed-wheel, and recovery-result semantic
  corrections are included, together with connected-assistant binding v18.

## Boundaries and known limitations

- OpenQASM 2 extraction is bounded. OpenQASM 3 is recognized and reported unsupported; no
  OpenQASM 3 parser or partial complete-circuit claim is included.
- Local evidence requires no qCoder account, token, Explorer service, MCP, or network request.
- The historical account-free OSS MCP is absent and is not restored.
- Exactly twelve deterministic Python-source motif identifiers are preserved. Motifs do not prove
  algorithm identity, correctness, completeness, result causation, performance, or advantage.
- Supplied results are reviewed factually; qCoder does not execute a simulator, backend, or QPU.
- No named-client support claim, Copilot behavior, telemetry, hidden persistence, project memory,
  cross-loop intelligence, or Pro hierarchy is added.
- Ordinary local reports may contain customer filenames and paths. Use `--share-safe-json` or
  `--share-safe-md` and inspect the output before sharing it.

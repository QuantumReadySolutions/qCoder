# qCoder 0.6.0a15

qCoder 0.6.0a15 is a behavior-changing pre-release successor to qCoder 0.6.0a13. It is not a
stable or generally available release, and package publication does not activate a named-client
support claim.

This release preserves decision-aware ordinary-language Blueprint preparation,
exact-selected-file local-first Evidence Review orchestration, and enforceable IDE-first
current-step authority ceilings. It compresses the ordinary native source-write handoff so one
binding-owned post-action operation records the action-specific native permission receipt and
registers the exact one-source output in one qCoder process. Separate lower-level authority and
registration operations remain fail-closed recovery primitives rather than normal customer
choreography.

Source generation still does not imply QASM export, execution, results, Evidence Review, or
governing-change authority. The release preserves exact semantic confirmation and lineage,
process-and-discard behavior, local raw-artifact authority, the share-safe protected boundary,
and exactly twelve public Context Bridge tools. Publication state, deployment state, and
qualification claims remain separate from immutable package metadata.

# qCoder 0.6.0a18+wi0436.structured.intent.recovery.v1

This is an unfrozen, unpublished WI-0436 development rehearsal identity. It is not a release
candidate and does not activate Tested, First-class, Client Compatibility, or public support.

The existing `create_algorithm_intent_card` operation now returns a bounded machine-readable
clarification contract whenever its exact card revision needs clarification. A client resupplies
that card and contract unchanged, supplies only customer-reviewed values for listed unresolved
fields, and explicitly asserts customer review. qCoder refuses stale, cross-card, cross-revision,
malformed, and forbidden corrections with field-local safe diagnostics that do not echo the raw
rejected value.

The change adds no public tool or authority category. It does not confirm intent automatically,
retain project state, execute code, alter WI-0435 causal evidence semantics, or change protected
production behavior. The twelve public Context Bridge tools and the two private Current Loop
operations remain unchanged.

Plain `0.6.0a17` remains immutable rejected-candidate history and must not be published.

# qCoder 0.6.0a14

qCoder 0.6.0a14 is a behavior-changing pre-release successor to qCoder 0.6.0a13. It is not a
stable or generally available release, and package publication does not activate a named-client
support claim.

This release adds decision-aware ordinary-language Blueprint preparation, exact-selected-file
local-first Evidence Review orchestration, and IDE-first current-step authority ceilings. Source
generation requires an exact native-client write boundary and does not imply QASM export,
execution, results, Evidence Review, or governing-change authority. Later steps require their own
bounded customer request and authority.

The release preserves exact semantic confirmation and lineage, process-and-discard behavior,
local raw-artifact authority, the share-safe protected boundary, and exactly twelve public Context
Bridge tools. Publication state, deployment state, and qualification claims remain separate from
immutable package metadata.

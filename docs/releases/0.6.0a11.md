# qCoder 0.6.0a11

qCoder 0.6.0a11 is an unpublished successor candidate to the public qCoder 0.6.0a10
pre-release at source freeze. Package-index publication remains a separate immutable lifecycle
fact.

This release repairs local Context Bridge token-file validation. After the existing supported
outer-whitespace normalization, qCoder now accepts only the exact Account issuer grammar: one
64-character value containing URL-safe ASCII letters, digits, `-`, and `_`. Impossible values fail
locally without a Context Bridge network request and without exposing their contents. The recovery
message directs customers to Account Center's **Copy token** action and tells them to replace the
local file value.

Valid existing 64-character tokens remain compatible. The protected service remains authoritative
for actual authentication, expiry, revocation, entitlement, and scope. This release changes no
Account issuance, consent, billing, entitlement, protected authentication, token scope, tool
inventory, binding-v18 contract, or public client qualification claim.
